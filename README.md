# Родовое древо Захаревич — Бунель

Семейный генеалогический альбом (Редакция 4.0): 4 поколения, 22 именованные персоны (+1 неизвестный сиблинг), ветви **Захаревич**, **Бунель**, **Хмыз**, **Адамович**, **Марунов**, **Винничек**, а также итоги архивного поиска ЦАМО / ОБД «Мемориал», ПМВ (`1914.svrt.ru`) и путеводитель по фондам НИАБ, ГАМн, ГАСО и ЗАГС.

## Структура проекта

- `data/family_tree.json` — структурированные данные по персонам, регионам, архивным фондам и документам ЦАМО.
- `src/build_tree_pdf.py` — генератор 8-страничного PDF-альбома формата A4 (портрет + альбомная схема древа).
- `fonts/` — шрифтовые гарнитуры (`Cormorant Garamond`, `Lora`, `PT Sans`).
- `Rodovoe_Drevo_Zaharevich_Bunel.pdf` — готовый PDF-альбом (Редакция 4.0).
- `.github/workflows/build-album.yml` — workflow GitHub Actions для сборки PDF и сохранения артефактов.

## Локальная сборка

```bash
pip install -r requirements.txt
python src/build_tree_pdf.py
```

## GitHub Actions

При каждом `push` (а также при ручном запуске через **Run workflow**) GitHub Actions пересобирает `Rodovoe_Drevo_Zaharevich_Bunel.pdf`, проверяет отсутствие предупреждений вёрстки и сохраняет готовый PDF (и PNG-превью страниц) в разделе **Actions → Artifacts**.
